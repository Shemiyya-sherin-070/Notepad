# Notepad

A simple Notepad desktop application developed using Python and Tkinter.

## Features

* Create a new document
* Open text files
* Save files
* Save As
* Cut
* Copy
* Paste
* Undo
* Redo
* Select All
* Scrollable text editor
* Simple and user-friendly GUI

## Technologies Used

* Python
* Tkinter

## Requirements

Python 3.3

Tkinter is included with most standard Python installations.

## How to Run

Clone the repository:

```bash
https://github.com/Shemiyya-sherin-070/Notepad.git

```

Open the project folder:

```bash
cd Notepad
```

Run the application:

```bash
py notepad.py
```
